# CodeAlpha Calculator

A fully responsive calculator built with vanilla HTML, CSS, and JavaScript.

##  Live Demo
https://simigy.github.io/CodeAlpha_Calculator/

##  Features
- Basic arithmetic: +, −, ×, ÷
- Decimal support
- Clear (AC) and Delete (DEL) buttons
- Light / Dark theme toggle with saved preference (localStorage)
- Full keyboard support (numbers, operators, Enter, Backspace, Escape)
- Responsive design for mobile and desktop
- Smooth transitions and hover effects

##  Built With
- HTML5
- CSS3 (CSS variables, Flexbox, Grid)
- Vanilla JavaScript (no libraries)
